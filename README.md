# Simple-Banking-System-in-C
## Project Description
This is a simple banking system developed using the C programming language.

## Features
- Deposit money
- Withdraw money
- Check balance
- Exit

## Technologies Used
- C Programming
- Structures
- Functions
- Switch Case
- Loops
- Conditional Statements

## How to Run
Compile the banking_system.c file using any C compiler and run the program.
